背景

训练算力一路狂奔,推理算力原地踏步

训练侧

更大的模型、更多的数据、更长的训练——缩放律十年有效,大投入的回报可预期。

推理侧

默认只让模型「试一次」;思维链只是让这一次更贵,并没有增加尝试的次数。

如果把「采样次数」当作推理算力的扩展轴,会发生什么?
方法

重复采样,两步走

Coverage覆盖

N 个样本里至少一个正确的题目比例——「能不能做出来」。

Precision精度

能否从一堆样本里挑出那个正确解——「能不能认出来」。

有自动验证器的任务,coverage 即成绩;没有验证器的任务,coverage 只是上限。

重复采样是吞吐优先的批处理负载,还能吃到共享前缀等推理系统优化,实际成本更低。

发现 ③

覆盖率遵循幂律——推理版缩放律

c ≈ exp(a · kb)

含义log(coverage) 随采样数 k 的幂平滑增长,四个数量级内近似对数线性。

类比训练缩放律让「买算力换 loss」可外推;这条让「买采样换性能」可外推。

家族规律同族模型的曲线形状相同,大模型只是把小模型的曲线向左平移(下页)。

多采样解锁的是「单次正确率 < 1%」的题——正确解在样本堆里是极少数派,多数投票天然投不出它,奖励模型也认不出它。

人工抽检:90% 以上的正确思维链推理忠实有效。信号存在,只是现有方法用不上。

发现 ④

饱和是普遍的,不是个例

细节与坑

自动验证器本身也有坑

Flaky 测试SWE-bench Lite 有 11.3% 的题测试结果不稳定(如 Python set 无序);作者对每个解连跑 11 次测试,取多数判定。

假阴性CodeContests 中 35/122 题存在「官方正确解却通不过测试」;对这些题,采样变成赌特定的输出格式。

独立采样所有尝试互不知晓:同一 prompt、同一温度,多样性只来自随机性——改进空间明确(多样条件、执行反馈、从失败中学习)。

为什么重要

一条与训练算力平行的扩展轴

能涨

coverage 在 4 个数量级的采样范围内平滑提升,弱模型可以被「放大」。

可预测

指数化幂律给出可外推的「推理算力 → 性能」公式。

卡在验证

无自动验证器时,多数投票与奖励模型在 ~100 样本处饱和。

发表于 o1(2024.09)前后,与 AlphaCode 的百万采样、o1 的长链思考互相印证;此后 PRM/ORM 验证器与 RL 推理的演进,正是沿着第 4 节指出的瓶颈展开。
