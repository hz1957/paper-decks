# RetroReasoner 电解液方向微调方案

现有 200～300 条（暂定）电解液材料的合成反应数据（碳酸酯、氟代醚、含 S/P/B 成膜添加剂等），计划在 RetroReasoner 上做继续训练。数据量比原训练集（ORDerly，52 万条）小三个数量级，所以方案偏保守：一期做数据构建 + A～C 对照微调实验 + 推理期重排；GRPO 和外部组件放二期，视一期结果决定是否启动。

## 1. 背景

基于模板/图的逆合成模型（Aizyfinder、LocalRetro 等）和 LLM 方法覆盖的反应空间重合度低——前者靠规则库保证常见反应的稳定召回，后者通过推理链处理规则库外的转化，两者天然互补。这是选用 RetroReasoner 并结合传统模型做 ensemble（见 3.2）的动机。

### 1.1 模型输出结构

RetroReasoner（Qwen3-8B）不是端到端翻译模型。首先，SyntheticRetro 管线把单步逆合成拆成四段结构化内容和三段过渡文本：

R1（产物官能团分析） $\rightarrow$ R2（锁定目标子结构） $\rightarrow$ R3（断键 + 合成子） $\rightarrow$ R4（还原为真实反应物）

R1～R4 由 RDKit 和原子映射规则生成，节点之间的 L12/L23/L34 三段自然语言（机理解释）由 LLM 生成；R4 之后还有 `<ANSWER>` 段，包装最终的反应物 SMILES。这思维链将作为训练数据对RetroReasoner进行微调。

推理时官方脚本只输入产物：system prompt 为 `You are a chemist.`，user prompt 为 `With the given product [SMILES], suggest some likely reactants that were used in its synthesis.`（训练数据中该模板有十种轮换表述，仅替换 SMILES）。无外部工具预计算 R1，整条轨迹由模型从产物 SMILES 自行生成。

训练只掩码 system/user prompt，assistant 输出的全部 token——从 R1 到 `<ANSWER>`——计入损失。所以微调时格式和推理流程不需要重新学，要学的是 R3 的断键选择是否符合电解液化学，以及 R1 能否覆盖电解液特征官能团。

### 1.2 为什么要微调

原模型训练数据来自 ORDerly（USPTO 专利反应），以药物类小分子为主。电解液分子的特点是小分子量、短合成步数（1～3 步）、F/S/P/B 杂原子密度高，涉及的氟化、酯交换、硫酸酯/磺内酯成环（DTD、1,3-PS 一类）、FEC 骨架等反应类型在通用数据里占比很低。零样本直接调用，预计主要错误是官能团漏检和断键位置偏差。是否需要微调可先量化判断：训前这 200～300 条尚未参与训练，可整体作为测试集，测零样本的 Pass@1 / Pass@16，与模型在通用数据上的命中率对比——预计会偏低；差距越明显，说明域差距越是主要误差来源，微调的收益空间越大。这本身就是 2.2 实验矩阵的 A 臂（零样本基线）——先跑一次拿到零样本在电解液数据上的命中率，既量化域差距，也作为后续消融的对比锚点。

### 1.3 为什么一期不做 RL

1. 论文自己的数据：SFT → RL 在 Exact@1 上只有约 1.4 个点的提升（0.512 → 0.526），而 Exact@100（0.734 vs 0.724）和多样性（3.898 vs 3.186）反而是 SFT 版更好。主要收益已在 SFT 阶段获得。
2. GRPO 的奖励完全来自正向验证器（round-trip forward model），而验证器本身是 ORDerly 训的，在电解液分子上准确率未知；200～300 条数据也训不出可靠的验证器。奖励错了，RL 是负收益。
3. 我们的场景是低并发、离线出路线，推理时多采样没有成本压力。Best-of-16 加规则过滤即可获得 RL 的大部分收益，且无训练成本。

## 2. 一期方案

### 2.1 数据准备

划分：200～300 条随机拆成两部分——独立测试集约 15～20%（40～55 条），其余约 210～250 条进 5 折交叉验证。CV 折用于 A～C 臂比较和超参、checkpoint 选择；独立测试集不参与任何选择，只在最终验收用一次。另从开源通用库抽约 1,500 条通用反应做回放（混入每次训练，防遗忘），并额外留出 500～1,000 条通用样本不参与训练，作遗忘测试集。

对训练反应按 SyntheticRetro 流程生成推理轨迹，有三处需要修改：

1. **原子映射质检**。先全量跑一遍 LocalMapper，统计在含 F/S/P 反应上的成功率；映射失败的样本人工补全（样本少，可覆盖）。R3 的断键位置直接由映射决定。
2. **扩充 SMARTS 字典**。SMARTS 是 RDKit 的子结构查询语言（相当于分子的"正则表达式"）。构造训练数据时，R1（`<PRODUCT_INFO>`）里的官能团名称和位置就是对产物 SMILES 跑一组 SMARTS 匹配得到的——官方实现用 RDKit 内置官能团加 MACCS keys，两者都是 SMARTS 模式。注意这一步影响的不是标签：R2/R3 的正确答案来自原子映射和键变化，与字典无关；字典决定的是 R1 能把产物描述得多完整，而推理时 R1 是模型自己生成的——若训练数据的 R1 中从未标注过磺内酯等基团，模型推理时便无法识别它们，即 1.2 节所述官能团漏检的来源。官方模式集按药物化学设计，需要在数据构造脚本里为电解液基团补写 SMARTS，例如 CF3 → `FC(F)F`、五元环状碳酸酯（EC 骨架）→ `O1C(=O)OCC1`、环状硫酸酯（DTD 骨架）→ `O=S1(=O)OCCO1`。要补的四类：
   - 碳酸酯：五元/六元环状、不对称链状
   - 含硫成膜添加剂：环状硫酸酯（DTD 类）、磺内酯（1,3-PS / PES 类）、亚硫酸酯
   - 氟代基团：CF3、CHF2、氟代烷氧基（氟代醚）、氟代碳酸酯位点
   - 含磷/硼/氮：磷酸三酯（如 `P(=O)(O[#6])(O[#6])O[#6]`）、亚磷酸酯、草酸硼酸盐、环状磷腈、腈类（`C#N`）
3. **扩增倍数从 ×15 降到 ×2～3，且只扩增训练折**。原论文每条反应生成 15 条不同过渡文本，前提是有 52 万条底物、每个 epoch 每条只出现一次；本数据照搬 ×15，模型会直接记住 R1～R4 的 SMILES。改成每条反应生成 2～3 条不同表述的过渡文本变体，且扩增只在各折训练部分内做——同一反应的变体 R2～R4 完全相同，跨折分布会把验证变成记忆测试。每折训练集 = 该折电解液变体约 350～600 条 + 1,500 条通用回放，约 2,000 条。

### 2.2 实验矩阵

微调不采用单一配置，以 A～C 三个对照臂验证基线和两个优化量级；R1 计入损失为论文原设计，各微调臂一致采用，不作消融：

| 臂 | 配置 | 目的 |
| --- | --- | --- |
| A | 官方 RL 权重，零样本 | 原模型能力的真实基线 |
| B | LoRA，`lr=2e-5`，1 epoch | 论文量级的 lr / 单次遍历是否学得动 |
| C | LoRA，`lr=1e-4`，至多 3 epoch | 更高 lr / 更多步数是否有效 |

B～C 共享配置：从官方 RL 权重起步，格式遵循和化学可行性先验已对齐，无需从 Qwen3-8B 重训；LoRA 只挂 MLP（`gate_proj` / `up_proj` / `down_proj`），attention 冻结，R1～R4 的格式和推理流程靠 attention 层既有模式维持；`r=16, alpha=16, dropout=0.05`，数据量不足以支撑更大的秩；batch 64；损失掩码与论文一致——prompt 段不计，R1 至 `<ANSWER>` 全部计入；每次训练混入 1,500 条通用回放。每臂在各折分别训一个模型，B～C 共 10 次训练，单次几十到百余步，算力可忽略，主要开销在数据制备。

### 2.3 评估协议

采样：temperature=1.0，每题 16 次；记录 Pass@1、Pass@16、Template Diversity，以及经 2.4 重排后的 Top-3 命中率。

A 臂另按官方协议跑一遍基线：greedy 解码算 Exact@1，temperature=1.2 采样 100 次算 Exact@100 与 Template Diversity，直接复用官方评估脚本（`eval_1_save_outputs.py` / `eval_2_save_metrics.py`），结果与论文报告值可比。臂间配对比较仍用上面的统一采样协议，不混口径。

臂间比较：5 折 pooled OOF 预测，同折同题做配对检验，主指标 Pass@1。以下两条为淘汰性约束，违反任一条的臂出局：

- Template Diversity 较 A 下降超过 30%（输出分布坍缩，模型开始记忆训练样本）。指标沿用论文定义：feasible 候选（经正向模型能复原产物）中不同规范反应模板的平均个数，正向判定用官方已发布的 RoundTrip-8B，模板提取用其评估代码内置的 LocalMapper；
- 遗忘测试集 Exact@1 较 A 下降超过 1.5 个百分点。遗忘在 2.1 留出的通用样本上测。

运行内早停：每 10 步在当前折验证部分采样 16 次，违反上述约束即停训并回滚 checkpoint。

最终验收：只对 A 和 CV 选出的臂在独立测试集上各跑一次，要求相对 A 在 Pass@1 / Top-3 命中率上配对提升显著（提升幅度超过 2～3 个百分点），且遗忘测试集指标无明显下降。选定后在除独立测试集外的全部数据上按固定配置重训一次，作为交付模型。

功效说明：CV 池约 210～250 条，配对检验能分辨大效应（B vs A、C vs B）；臂间差距在 2～3 个百分点以内视为平局，取更简单的臂。

P1（模板 OOD）：先统计反应模板分布。若多数模板只有一条反应，不做模板切分评估，只报告模板覆盖率；对成员数足够的模板类可另做小规模 OOD 测试，不参与选择。

### 2.4 推理部署

交付给合成团队的不是单次预测，而是：

1. 模型从产物 SMILES 生成完整推理轨迹（与官方推理协议一致，无外部注入）；
2. vLLM 并发采样 $N=16$ 条完整推理轨迹；
3. RDKit 硬过滤：格式不闭合、反应物 SMILES 非法、原子明显不守恒的直接丢弃；
4. 按 log-prob 加前体商业可得性（是否命中常见基础化工品/氟化工原料库）排序，输出 Top-3 路线，附 L12～L34 机理解释供人判断。

## 3. 二期（视一期结果决定）

### 3.1 GRPO

触发条件：一期模型 Pass@16 较高（能采样出正确路线），但重排后 Top-3 不稳定——说明正确答案已在输出分布内、置信度排序不佳，此时 RL 才有明确收益。

前提是先解决验证器：

- 用 250 条电解液正向数据（reactants → product）加 1,000 条通用数据微调 Qwen3-0.6B/8B 正向模型，在电解液验证集上正向 Top-1 ≥ 85% 才能用作奖励信号；达不到则不启动 GRPO。
- 奖励不用纯 0/1 round-trip——样本少，组内全对或全错时 GRPO 梯度消失。改混合奖励，tanimoto 项对预测反应物和真实反应物的 Morgan 指纹相似度，对部分正确的输出也能产生梯度信号：

  $$
  R_{\text{total}} = 0.6 R_{\text{round-trip}} + 0.3 R_{\text{tanimoto}} + 0.1 R_{\text{format}}
  $$

- rollout 池可以混入 1,000+ 个从文献或生成模型收集的电解液候选分子（只需产物 SMILES），扩大探索面。

若不维护在线 GRPO 框架，退化方案是离线 RFT：用一期模型对无标签分子采样，验证器过滤，高质量轨迹并回训练集再跑 1 epoch LoRA。效果有所折损，但工程量小得多。

### 3.2 外部组件

按需接入，均不改动模型本身：

- **ChemCensor 做重排信号**（C3LM / Solvent 一系工作）：2.4 的重排目前只有 log-prob 加可得性，可以补一项化学合理性打分。对没有参考答案的新型含氟/含硫路线，覆盖面比自训的 round-trip 验证器广。
- **MORetro\* 做多步规划**：目标分子需要 2～4 步合成时，不用原论文的 MCTS，将微调后的模型作为单步展开算子接入 MORetro\*。可以直接用它的原料价格（MolPrice）和毒性（EToxPred）评估出 Pareto 前沿路线集——电解液工艺对前体毒性和成本敏感（氟化/硫代试剂），这比单纯的"能否解出"更贴近实际需求。
- **与传统模型 ensemble**：C3LM 的结论是 LLM 与模板/图模型（RetroPrime、LocalRetro 一类）覆盖的反应空间重合度低。生产环境可以把两边预测合并去重后送重排器，提召回。
