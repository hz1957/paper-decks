# RetroReasoner 电解液方向微调方案

手头有 200~300 条电解液材料的合成反应数据（碳酸酯、氟代醚、含 S/P/B 成膜添加剂等），计划在 RetroReasoner 上做继续训练。数据量比原训练集（ORDerly，52 万条）小三个数量级，所以方案以稳为主：一期只做数据构建 + LoRA SFT + 推理期重排；GRPO 和外部组件放二期，视一期结果决定做不做。

## 1. 背景

### 1.1 模型输出结构

RetroReasoner（Qwen3-8B）不是端到端翻译模型。SyntheticRetro 管线把单步逆合成拆成四段结构化内容和三段过渡文本：

R1（产物官能团分析） $\rightarrow$ R2（锁定目标子结构） $\rightarrow$ R3（断键 + 合成子） $\rightarrow$ R4（还原为真实反应物）

R1~R4 由 RDKit 和原子映射规则生成，节点之间的 L12/L23/L34 三段自然语言（机理解释）由 LLM 生成。这个结构对微调有一个直接影响：格式和推理流程不需要重新学，要学的只是 R3 的断键选择是否符合电解液化学。

### 1.2 为什么要微调

原模型训练数据来自 ORDerly（USPTO 专利反应），以药物类小分子为主。电解液分子的特点是小分子量、短合成步数（1~3 步）、F/S/P/B 杂原子密度高，涉及的氟化、酯交换、硫酸酯/磺内酯成环（DTD、1,3-PS 一类）、FEC 骨架等反应类型在通用数据里占比很低。零样本直接调用，预计主要错误是官能团漏检和断键位置偏差，训前用探针测试确认（见 2.2）。

### 1.3 为什么一期不做 RL

1. 论文自己的数据：SFT → RL 在 Exact@1 上只有约 1.4 个点的提升（0.512 → 0.526），而 Exact@100（0.734 vs 0.724）和多样性（3.898 vs 3.186）反而是 SFT 版更好。主要收益在 SFT 阶段已经拿到。
2. GRPO 的奖励完全来自正向验证器（round-trip forward model），而验证器本身是 ORDerly 训的，在电解液分子上准确率未知；200~300 条数据也训不出可靠的验证器。奖励错了，RL 是负收益。
3. 我们的场景是低并发、离线出路线，推理时多采样没有成本压力。Best-of-16 加规则过滤能拿到大部分 RL 想要的效果，不用付训练成本。

## 2. 一期方案

### 2.1 数据准备

划分：200~300 条按分子骨架（scaffold）拆成 250 条训练、30~50 条验证——训练和验证集不能有同骨架分子，否则早停信号失真。另从开源通用库抽约 1,500 条通用反应做回放，防遗忘。

对 250 条训练数据按 SyntheticRetro 流程生成推理轨迹，有三处要改：

1. **原子映射质检**。先全量跑一遍 LocalMapper，统计在含 F/S/P 反应上的成功率；失败的人工补映射（量小，可行）。R3 的断键位置直接由映射决定，这步不能省。
2. **扩充 SMARTS 字典**。SMARTS 是 RDKit 的子结构查询语言（相当于分子的"正则表达式"）。构造训练数据时，R1（`<PRODUCT_INFO>`）里的官能团名称和位置就是对产物 SMILES 跑一组 SMARTS 匹配得到的——官方实现用 RDKit 内置官能团加 MACCS keys，两者都是 SMARTS 模式。注意这一步影响的不是标签：R2/R3 的正确答案来自原子映射和键变化，与字典无关；字典决定的是 R1 能把产物描述得多完整，而推理时 R1 是模型自己生成的——训练数据里 R1 从没点名过磺内酯，模型推理时就学不会点出它，这正是 1.2 节说的官能团漏检来源。官方模式集按药物化学设计，需要在数据构造脚本里为电解液基团补写 SMARTS，例如 CF3 → `FC(F)F`、五元环状碳酸酯（EC 骨架）→ `O1C(=O)OCC1`、环状硫酸酯（DTD 骨架）→ `O=S1(=O)OCCO1`。要补的四类：
   - 碳酸酯：五元/六元环状、不对称链状
   - 含硫成膜添加剂：环状硫酸酯（DTD 类）、磺内酯（1,3-PS / PES 类）、亚硫酸酯
   - 氟代基团：CF3、CHF2、氟代烷氧基（氟代醚）、氟代碳酸酯位点
   - 含磷/硼/氮：磷酸三酯（如 `P(=O)(O[#6])(O[#6])O[#6]`）、亚磷酸酯、草酸硼酸盐、环状磷腈、腈类（`C#N`）
3. **扩增倍数从 ×15 降到 ×2~3**。原论文每条反应生成 15 条不同过渡文本，前提是有 52 万条底物、每个 epoch 每条只出现一次。250 条数据照搬 ×15，模型会把 R1~R4 的 SMILES 背下来。改成每条生成 2~3 条不同表述的过渡文本，得 500~750 条电解液轨迹，与约 1,500 条通用轨迹按 1:2~1:3 混合，最终训练集 2,000~2,200 条左右。

### 2.2 训前基线

训练前用官方 RetroReasoner (RL) 权重在验证集上跑零样本（temperature=1.0，每题采样 16 次），记录三个数：Pass@1、Pass@16、平均 unique 合法反应物数。这是后面判断有没有训坏的对照。

### 2.3 训练配置

从官方 RL 权重起步——格式遵循和化学可行性先验已经对齐好，没必要从 Qwen3-8B 重训。

| 项 | 设定 | 理由 |
| --- | --- | --- |
| 微调方式 | LoRA，只挂 MLP（`gate_proj` / `up_proj` / `down_proj`） | 冻结 attention。R1~R4 的格式和推理流程靠 attention 层的既有模式维持，动它风险大、收益小 |
| LoRA 超参 | `r=16, alpha=16, dropout=0.05` | 250 条数据撑不起更大的秩，参数量压到最小 |
| 优化 | `lr=2e-5`，batch 64，1 epoch | 全程约 30~35 步。目标是认识新的断键模式，不是重学任务 |
| 损失掩码 | prompt 和 R1（`PRODUCT_INFO`）段不计损失 | 梯度集中在 L12~R4，即过渡文本、断键、还原三段 |

早停：每 10 步在验证集上采样 16 次，出现以下任一情况停训并回滚 checkpoint：

- unique 反应物数比 2.2 基线掉 30% 以上（输出分布坍缩，模型开始背样本）；
- 通用回放集 Exact@1 掉 1.5 个点以上（遗忘）。

### 2.4 推理部署

交付给合成团队的不是单次预测，而是：

1. vLLM 并发采样 $N=16$ 条完整推理轨迹；
2. RDKit 硬过滤：格式不闭合、反应物 SMILES 非法、原子明显不守恒的直接丢弃；
3. 按 log-prob 加前体商业可得性（是否命中常见基础化工品/氟化工原料库）排序，输出 Top-3 路线，附 L12~L34 机理解释供人判断。

验收标准：验证集 Pass@1 和重排后 Top-3 命中率相对零样本基线有明确提升，且通用回放集指标不掉。

## 3. 二期（视一期结果决定）

### 3.1 GRPO

触发条件：一期模型 Pass@16 不错（正确路线采得出来），但重排后 Top-3 不稳定——说明答案在分布里、置信度排序不行，这时 RL 才有明确收益。

前提是先解决验证器：

- 用 250 条电解液正向数据（reactants → product）加 1,000 条通用数据微调 Qwen3-0.6B/8B 正向模型，在电解液验证集上正向 Top-1 ≥ 85% 才能拿来做奖励；达不到就不做 GRPO。
- 奖励不用纯 0/1 round-trip——样本少，组内全对或全错时 GRPO 梯度消失。改混合奖励，tanimoto 项对预测反应物和真实反应物的 Morgan 指纹相似度，给部分正确的输出非零信号：

  $$
  R_{\text{total}} = 0.6 R_{\text{round-trip}} + 0.3 R_{\text{tanimoto}} + 0.1 R_{\text{format}}
  $$

- rollout 池可以混入 1,000+ 个从文献或生成模型收集的电解液候选分子（只需产物 SMILES），扩大探索面。

不想维护在线 GRPO 框架的话，退化方案是离线 RFT：用一期模型对无标签分子采样，验证器过滤，高质量轨迹并回训练集再跑 1 epoch LoRA。效果打折，工程量小得多。

### 3.2 外部组件

按需接入，都不动模型本身：

- **ChemCensor 做重排信号**（C3LM / Solvent 一系工作）：2.4 的重排目前只有 log-prob 加可得性，可以补一项化学合理性打分。对没有参考答案的新型含氟/含硫路线，覆盖面比自训的 round-trip 验证器广。
- **MORetro\* 做多步规划**：目标分子需要 2~4 步合成时，不用原论文的 MCTS，把微调后的模型当单步展开算子接进 MORetro\*。可以直接用它的原料价格（MolPrice）和毒性（EToxPred）评估出 Pareto 前沿路线集——电解液工艺对前体毒性和成本敏感（氟化/硫代试剂），这比单纯的"能否解出"更贴近实际需求。
- **与传统模型 ensemble**：C3LM 的结论是 LLM 与模板/图模型（RetroPrime、LocalRetro 一类）覆盖的反应空间重合度低。生产环境可以把两边预测合并去重后送重排器，提召回。
